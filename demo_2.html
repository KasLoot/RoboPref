PrefMem · Preference-aware robot autonomy

Tell your robot once. It remembers.

PrefMem is an agentic layer that sits above any VLA-driven robot. It clarifies ambiguous instructions before acting, distills your answers into durable preferences, plans and executes sub-tasks on the robot, and visually validates its own work — a closed loop that gets quieter and more personal with every task.

Everything below is a real recorded session — six tasks on a dual-arm tabletop robot, replayed verbatim from system logs. No outputs were edited.

Architecture

Five agents, one closed loop

A single conversation with the user drives the whole pipeline. The memory curator runs alongside execution, so learning never adds latency to the task.

01 · INTERFACE

Human-Interaction

Grounds your words to objects in view. Asks only when the request is genuinely ambiguous — and never twice for the same thing.

→
02 · LEARNS

Memory Curator

Extracts preferences from your answers with evidence quotes. Candidates become durable once confirmed; corrections overwrite instantly.

→
03 · PLANS

Planner

Reads the live scene, decomposes intent into pick-and-place sub-tasks, and assigns each one to the best arm.

→
04 · ACTS

VLA Executor

Runs each sub-task on the robot's vision-language-action policy. Works with any VLA backbone.

→
05 · CHECKS

Validator

Compares the final camera frame against the expected outcome. On a mismatch, it sends the discrepancy back to the planner — automatically.

Failed validation loops back to planning without human intervention. The user only ever sees one of two things: a single clarifying question, or a completed task.
